# منصة أثيريا المعرفية | Aetheria Knowledge Platform

> منصة استكشافية وتوثيقية شاملة للعلوم، الفضاء، التكنولوجيا، الفن، الأدب، وديوان الأعلام والسير الذاتية.

---

## ⚡ طرق التشغيل بعد فك ضغط ملف الـ ZIP

المشروع مُجهز ليعمل **فوراً وبأكثر من طريقة** تناسب ما تفضله:

### 🌟 الطريقة 1: التشغيل المباشر عبر Live Server في VS Code (بدون تثبيت أو تجهيز أي شيء)

**لا تحتاج لتثبيت Node.js أو تشغيل أي أوامر في سطر الأوامر على الإطلاق!**

1. فك ضغط ملف الـ ZIP وافتح مجلد المشروع في برنامج **VS Code**.
2. انقر بزر الفأرة الأيمن على ملف `index.html` (أو `live_server.html` أو `dist/index.html`) واختر:
   👉 **"Open with Live Server"**
   *(أو اضغط على زر **Go Live** في الشريط السفلي لبرنامج VS Code).*
3. سيفتح الموقع فوراً في المتصفح ويعمل بكامل محتواه، ومقالاته، وتصميماته، ولوحة إدارته!

---

### 🚀 الطريقة 2: التشغيل التلقائي بنقرة واحدة (One-Click عبر Node.js)

إذا كان لديك Node.js مثبت على جهازك:
- **مستخدمو ويندوز (Windows)**: انقر نقراً مزدوجاً على ملف `start.bat`.
- **مستخدمو ماك ولينكس (macOS / Linux)**: شغّل الملف التنفيذي `./start.sh`.
- سيقوم الملف تلقائياً بالتحقق من الحزم وتشغيل الخادم على الرابط: `http://localhost:3000`.

---

### 💻 الطريقة 3: التشغيل اليدوي عبر الطرفية (Manual CLI)

```bash
# 1. الدخول لمجلد المشروع
cd aetheria-knowledge-platform

# 2. تثبيت الحزم
npm install

# 3. تشغيل وضع التطوير
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

## 🚀 تشغيل وضع الإنتاج (Production Build)

إذا رغبت في بناء وتشغيل المنصة كنسخة إنتاج جاهزة ومجمعة بالكامل:

```bash
# 1. تجميع وبناء المشروع
npm run build

# 2. بدء الخادم الإنتاجي
npm start
```

## 💾 قاعدة البيانات والتخزين الذاتي (Zero-Config Database)

- لا تحتاج إلى تثبيت أي خادم قواعد بيانات خارجي (مثل MySQL أو MongoDB).
- يعتمد النظام على تخزين ذري آمن للملفات في المسار `data/db.json`.
- يحتوي تلقائياً على كافة المقالات الافتراضية، وسير الأعلام، والمستخدمين، والإشعارات، مع ميزة التحديث الذري لمنع تلف البيانات.
- يمكنك أيضاً تصدير نسخة احتياطية بنقرة واحدة من لوحة المسؤول (`Export DB`).

## 🛠️ الأوامر المتاحة في المشروع (Available Scripts)

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل خادم التطوير التفاعلي مع Vite وExpress |
| `npm run build` | بناء نسخة الإنتاج المجمعة (Vite + esbuild) |
| `npm start` | تشغيل الخادم الإنتاجي المجمع في `dist/` |
| `npm run lint` | فحص صحة أنواع TypeScript |
| `npm run clean` | مسح مجلد الإنتاج `dist/` |
